This memo explains who my portfolio is written for and how I chose its content, layout, and visual design.

Target employer and the skills it values

I most want to work in an R&D group that builds robots, haptic devices, or medical devices that must sense touch, such as a robotics company developing dexterous grippers or a lab developing soft wearable sensors. Job postings for these roles repeatedly ask for five skills:

  • sensor design and prototyping, including soft-material fabrication;
  • experimental testing and automation with load frames, robots, and instrumentation;
  • data analysis and machine learning in Python or MATLAB;
  • electronics and embedded control (microcontrollers, motor drivers, PCB tools);
  • communication and teamwork across disciplines.

Content choices and tailoring

I included seven projects and ordered them by relevance to this employer rather than by date. The tactile-sensor research comes first because it demonstrates all four technical skills in one system. The switchable-adhesive and flexible-resin projects follow because they show soft-material fabrication and characterization. The peel-test capstone shows electronics and motor control. 1touch, my course-assistant role, and STEM outreach show scoping, communication, and leadership.

Each project page begins with the social value of the work and a one-sentence objective, then follows IMRD (research) or IDEC (design) headings so readers know where to find methods and results. A "My role" box separates my contributions from the team's, and a "Skills used" list repeats the same skill names that appear on my home page and resume, so a skimming recruiter sees consistent keywords. I removed the theme's placeholder projects and personal social-media links because they did not support this audience.

I also revised my resume. I moved Skills to the top, grouped by the four skill areas above, and used standard headings (Skills, Education, Experience) that applicant-tracking software recognizes. Every bullet now begins with a verb, with present tense for current roles and past tense for completed ones, and I corrected typos such as "Gannt."

Layout and aesthetic choices

The home page follows how employers skim: my name, a one-line role statement, and a short introduction appear first, followed immediately by a core-skills grid and then project cards. All text is left-aligned because left-aligned text is faster to scan than the theme's original centered text. I used one sans-serif typeface (Inter), limited body lines to about 65 characters, and kept a single blue accent for links and skill tags so color signals what is important. Every project has a labeled diagram so readers understand the system before reading the text. Navigation has only three items (Projects, About, Resume), every project links to the next one, and I checked every internal link and image with an automated crawler.
